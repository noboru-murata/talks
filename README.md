# 講演資料

村田 昇の講演資料 (スライド・配布用 PDF・解説文・デモ) を公開する場所．
一覧は GitHub Pages の `index.html`．

## ライセンス

- **資料** (スライド，配布用 PDF，解説文，図): [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/deed.ja) (`LICENSE`)．
  出典を示せば，営利目的でない限り共有・改変してよい．
- **コード** (デモの html に含まれるスクリプト，`tools/`): MIT (`LICENSE-CODE`)．
- **第三者の部品**: スライドに埋め込まれた reveal.js (MIT)，MathJax (Apache-2.0)，フォントなどは，
  それぞれ元のライセンスに従う．
- **引用した図**: 他の文献から引用した図は，その出典の権利者に属し，上のライセンスの対象外．
- 講演ごとに異なる場合は，その講演の `meta.yml` の `license` に従う．

## このリポジトリについて

講演の原本は別のリポジトリにあり，ここには各講演の `make publish` が写したものだけを置く．
取り決めは `PUBLISHING.md`．
