条件から解へ: 条件付き PINN と作用素学習

問題5 と問題6 の学習済みの NN を，このブラウザの中で動かします。学習は前もって済ませてあり，ここで行うのは順伝播 (推論) と終点の射影だけです。条件や入力の折れ線を動かすと，その場で滑らかな経路が返ってきます。1 件ずつ最適化する方法 (問題4) では 1 件に約 25 秒かかります。

平面図 · 単位 m · 格子 20 m

終点の条件

図の終点 (橙の点) と方位のハンドルはドラッグで動かせます。始点は原点・方位 0° に固定。「学習した範囲から選ぶ」は，学習に使ったのと同じ作り方 (直線 → クロソイド → 円弧 → クロソイド) で条件を作り，その曲線を灰色の帯で示します。

入力の折れ線

折れ線の角 (橙の点) をドラッグで動かせます。始点は原点，最初の区間は x 軸の向き。NN は折れ線の方位角を等間隔の N 点で読みます (学習は N = 128)。点の数を変えても同じ重みのまま使えるのが作用素学習の特徴です。

問題5: 条件付き PINN

NN の入力に弧長 t のほか条件 c = (φf, xf/L, yf/L, L/100) を加え，(t, c) → dκ/dt を学ぶ。積分層で κ → φ → (x, y) を作るので運動学は構造で成り立ち，終点はここで行う射影 (4 本の多項式の補正) で厳密に合わせる。学習は条件の分布全体について一度だけ。

問題6: 作用素学習 (FNO)

入力は数の組ではなく関数 (折れ線の方位角 φraw(s))。FNO の層は関数をフーリエ級数に直し，低い 16 個のモードに重みを掛けて戻す。重みは格子点ではなくモードに付くので，読む点の数 N を変えても同じ重みが使える (解像度不変)。正解の曲線は与えていない (教師なし)。

射影

NN の出力 j(t) に低次のルジャンドル多項式 4 本の補正 Σ c_m ψ_m(t) を足し，終点の (κ, φ, x, y) が条件に一致するよう c をレーベンバーグ・マーカート法で決める。灰色の細線は射影の前の出力。
